# Vendor Portal - Frontend

This is the React-based frontend for the Vendor Onboarding Portal.

## 🚀 Quick Start

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

## 🛠️ Technology Stack
- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Vanilla CSS (Custom Design System)
- **Language**: TypeScript

## 🎨 Design Tokens
- **Primary Color**: `#6366f1` (Indigo)
- **Background**: `#0f172a` (Deep Blue)
- **Animations**: CSS Keyframes (Fade, Shimmer, Slide)
- **Effects**: Glassmorphism (Backdrop-filter: blur)

## 📁 Directory Structure
- `src/components`: UI components.
- `src/services`: API client and services.
- `src/types.ts`: Shared TypeScript interfaces.
- `src/index.css`: Global design system and animations.
